# AI Code Reviewer diagrams

These slide-ready diagrams show the project's main architecture and two review paths.

- `system-architecture.svg` - high-level components and where findings go.
- `pr-review-workflow.svg` - automatic GitHub pull request review flow.
- `quick-check-workflow.svg` - standalone code review flow and optional PR action.

The SVG files are vector graphics and remain sharp when resized. For PowerPoint, insert them as SVG images. The diagrams use a 1600 x 900 (16:9) canvas and are written for presentation, not as a substitute for detailed implementation documentation.
